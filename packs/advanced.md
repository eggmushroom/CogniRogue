## 动态规划

### 一个问题能用动态规划求解，通常需要同时满足哪两条性质？
A) 最优子结构，以及子问题大量重叠
B) 数据有序，以及可以二分
C) 图无环，以及边权非负
D) 状态数是偶数，以及转移是线性的
= A
+ 最优子结构保证「大问题的最优解能由小问题拼出来」，重叠子问题才值得把解存下来；只有前者没有后者，分治就够了。

? 理解: 只有最优子结构、子问题互不重叠时，更自然的解法是？
A) 分治
B) 回溯
C) 贪心
D) 随机化
= A
+ 子问题不重复就没有「存下来复用」的收益，直接递归拆开即可，比如归并排序。

? 迁移: 求斐波那契数用朴素递归是 O(2^n)、用 DP 是 O(n)，差别来自？
A) DP 用了更少的乘法
B) 同一个子问题被重复计算了指数次，DP 每个只算一次
C) 递归不能返回整数
D) DP 不需要边界条件
= B
+ f(n-2) 在左右两条分支里各算一遍，越往下重复越严重；记忆化把每个 f(k) 只算一次。

### 0/1 背包用一维数组 dp[j] 表示容量 j 的最大价值，内层循环必须怎么做？
A) 容量 j 从大到小遍历
B) 容量 j 从小到大遍历
C) 与遍历方向无关
D) 按物品价值排序后从小到大
= A
+ 逆序遍历保证更新 dp[j] 时，dp[j-w] 还是「上一件物品」的状态；正序会让同一件物品被重复放入，变成完全背包。

? 理解: 如果内层改成从小到大遍历，语义会变成？
A) 完全背包，每件物品可取无限次
B) 多重背包
C) 结果不变
D) 无法计算
= A
+ 因为 dp[j-w] 已经被本轮这件物品更新过，转移时等于又拿了一次，正好是完全背包的定义。

? 迁移: 相比一维滚动数组，二维 dp[i][j] 的主要好处是？
A) 时间复杂度更低
B) 能重建具体选了哪些物品，且不用担心遍历方向
C) 支持负数重量
D) 空间更省
= B
+ 二维状态天然把「考虑前 i 件」和「前 i-1 件」隔开，不存在覆盖问题，代价是 O(nW) 空间。

### 两个序列的最长公共子序列（LCS），当末尾字符不相等时的状态转移是？
A) dp[i][j] = max(dp[i-1][j], dp[i][j-1])
B) dp[i][j] = dp[i-1][j-1]
C) dp[i][j] = dp[i-1][j-1] + 1
D) dp[i][j] = min(dp[i-1][j], dp[i][j-1])
= A
+ 末尾不同，最优解只能来自「丢掉 a 的末尾」或「丢掉 b 的末尾」之一，取较大；相等时才是 dp[i-1][j-1]+1。

? 理解: LCS 与最长公共子串的关键差别是？
A) 子序列不要求连续，子串要求连续
B) LCS 只适用于数字
C) 子串允许跳过字符
D) 两者完全相同
= A
+ 连续性让子串在末尾不匹配时可以直接归零，状态转移反而比 LCS 更简单。

? 迁移: 两个长度 n 的序列做 LCS，标准 DP 的时间和空间是？
A) O(n) / O(1)
B) O(n²) / O(n²)
C) O(n log n) / O(n)
D) O(2^n) / O(n)
= B
+ 填满 n×n 的表就是 O(n²)；只求长度时可以用滚动数组把空间压到 O(n)，但时间降不下来。

### 自顶向下记忆化搜索相比自底向上递推，一个实际的好处是？
A) 只计算真正被递归访问到的状态
B) 一定更省空间
C) 不需要边界条件
D) 时间复杂度低一个数量级
= A
+ 状态空间很大但可达状态稀疏时（比如带约束的棋盘 DP），记忆化能跳过大量永远用不到的格子。

? 理解: 记忆化搜索通常比递推多出来的开销是？
A) 需要排序
B) 递归调用栈与哈希表的查找开销
C) 要预分配全部状态
D) 不能并行
= B
+ 递推用数组下标直接访问，记忆化要查缓存、还要压栈；常数往往更大。

? 迁移: 状态转移里存在环时，必须先做什么？
A) 按拓扑序处理或先判环，否则记忆化会无限递归
B) 把状态改成一维数组
C) 加大缓存容量
D) 改成贪心
= A
+ 有环图上的「最长路」这类 DP 不是良定义的；要么先缩点成 DAG 按拓扑序算，要么改成最短路的松弛迭代。

### 最长递增子序列（LIS）的 O(n log n) 解法维护的是什么？
A) 数组 tails：每个长度下结尾最小的那个元素
B) 所有递增子序列的列表
C) 一个长度为 n 的二维表
D) 前缀和数组
= A
+ tails[k] 存「长度为 k+1 的递增子序列里最小的末尾」，它对 k 单调递增，因此可以二分插入。

? 理解: 为什么 tails 数组可以二分？
A) 更长的递增子序列，其最小末尾一定不小于更短的
B) 输入数组本身有序
C) tails 长度固定
D) 元素都是整数
= A
+ 若 tails[k] < tails[k-1]，那长度 k+1 的序列去掉末尾就得到一个末尾更小的长度 k 序列，与「最小」矛盾。

? 迁移: 这个 tails 数组本身是不是一条合法的 LIS？
A) 不是，它只是各长度下的末尾最小值，未必来自同一条序列
B) 一定是
C) 当输入有序时才是
D) 只有当 n 是偶数时才是
= A
+ 二分替换会混入不同序列的元素；要还原真实 LIS 还得额外记录每个位置的前驱。

### DP 里用「滚动数组」把二维表压成一维，成立的前提是？
A) 当前行只依赖上一行（或少数几行）
B) 状态值都是 0 或 1
C) 输入规模是 2 的幂
D) 转移不涉及加法
= A
+ 只要不回溯到更早的行，旧行用完即可覆盖；若转移需要前面所有行，就不能压掉。

? 理解: 状压 DP 用一个整数的二进制位表示集合，主要适用于什么规模？
A) 集合元素很少（通常 n 不超过二十左右）
B) 集合元素上百万
C) 任意规模
D) 只有空集
= A
+ 状态数是 2^n，n 稍大就爆炸；它换来的是「集合的包含关系」能用一次位运算算完。

? 迁移: 滚动数组最常带来的代价是？
A) 无法再回溯重建完整方案
B) 时间复杂度上升
C) 结果会变错
D) 必须改成递归
= A
+ 旧状态被覆盖掉了；如果题目要求输出具体路径而不只是最优值，就得保留整张表或另存决策。

## 贪心策略

### 贪心算法能拿到全局最优解，通常需要问题具备？
A) 数据必须有序
B) 状态数是多项式
C) 贪心选择性质：局部最优不会被后续推翻，且最优子结构成立
D) 所有边权相等
= C
+ 贪心不做回退，所以每一步的局部最优必须能接上某个全局最优解；证明常用交换论证。

? 理解: 用「交换论证」证明贪心正确，核心动作是？
A) 说明任意最优解都能在不变差的前提下换成贪心选的那个
B) 枚举所有解
C) 计算运行时间
D) 构造反例
= A
+ 把最优解里第一个与贪心不同的选择替换掉，若目标值不下降，递归下去就说明贪心解也是最优。

? 迁移: 找零钱问题里硬币面额 1、3、4，凑 6 元，用「每次取不超过余额的最大面额」会得到？
A) 4+1+1 共 3 枚，而最优是 3+3 共 2 枚，贪心失效
B) 一定最优
C) 无解
D) 与 DP 结果相同
= A
+ 面额不满足「规范币制」，局部最大反而把路堵死；这类题必须换成完全背包 DP。

### 区间调度（选最多个互不重叠的区间）的经典贪心是按什么排序？
A) 按结束时间从早到晚
B) 按开始时间从早到晚
C) 按区间长度从短到长
D) 按开始时间从晚到早
= A
+ 越早结束，留给后面的时间越多；按结束时间选第一个兼容区间，交换论证可证最优。

? 理解: 为什么按「最短区间优先」不一定最优？
A) 一个很短的区间可能横跨两个本来都能选的长区间
B) 短区间无法排序
C) 短区间一定重叠
D) 时间复杂度太高
= A
+ 目标是最多数量，关键是「结束得早」，不是「占得少」；这两件事在位置上不是一回事。

? 迁移: 若每个区间带权重、要最大化总权重，该改用？
A) 按结束时间排序的加权区间调度 DP
B) 仍然按结束时间贪心
C) BFS
D) 并查集
= A
+ 加权之后局部最优不再能推出全局最优，需要先按结束时间排序，再做「选 / 不选」的 DP。

### 分数背包能用「按单位价值从高到低装」贪心，0/1 背包却不行的原因是？
A) 0/1 背包的物品更多
B) 可切分保证最后一次总能正好装满，不存在「装不下又不能拆」的浪费
C) 分数背包的物品价值更小
D) 0/1 背包不能排序
= B
+ 完整性约束让「单位价值最高」的物品可能占掉容量却留下空隙，交换论证在这里断掉，必须靠 DP 枚举取舍。

? 理解: 容量 50，物品（重, 值）为 (10,60)、(20,100)、(30,120)，0/1 背包最优价值是？
A) 220，选后两件
B) 240，选第一件和第三件
C) 180，只选中间一件
D) 280，三件都选
= A
+ 20+30 正好装满得 220；按单位价值贪心会先拿 (10,60) 和 (20,100)，只得到 160，剩下的 20 装不下第三件。

? 迁移: 同样这组数据，分数背包按单位价值贪心能拿到？
A) 240：先拿前两件，再从第三件切 20/30 拿走 80
B) 220
C) 160
D) 280
= A
+ 切分让剩下的 20 容量也能按剩余最高单位价值填满，贪心在这里恰好达到上界。

### 只允许一次买卖、求最大利润，O(n) 的做法是？
A) 枚举所有买入卖出日组合
B) 扫描时维护到当前为止的最低买入价，用今天价格减它更新答案
C) 排序后取最大值减最小值
D) 用二分查找
= B
+ 卖出日固定在「今天」时，最好的买入日一定是之前的最低点；一次扫描就够了。

? 理解: 为什么「最大值减最小值」是错的？
A) 最小值可能出现在最大值之后，时间顺序不允许先卖后买
B) 数组里可能有负数价格
C) 浮点数不精确
D) 结果会溢出
= A
+ 这道题的约束是顺序，不是数值大小；丢掉下标信息会把不可行的交易对算进来。

? 迁移: 如果允许任意多次交易（同一天不能同时买卖），最优贪心策略是？
A) 把所有上涨的相邻差价都加起来
B) 只取最大的一段上涨
C) 取全局最低点买入、最高点卖出
D) 必须改成 DP
= A
+ 每段连续上涨拆成相邻天的差价之和完全等价，于是「见涨就吃」就是最优。

### 一个贪心策略在样例上「看起来总是对」，最稳妥的下一步是？
A) 要么给出交换论证，要么主动找反例；跑对样例不算证明
B) 增加测试用例数量即可
C) 把排序改成从大到小
D) 直接改成暴力枚举
= A
+ 贪心最危险的地方就是「样例全过」：它要么有结构性证明，要么等着被一组边界数据推翻。

? 理解: 与 DP 相比，贪心每步决策的显著特征是？
A) 一旦做出就不再回退，也不保留其他候选
B) 会枚举所有子问题的解
C) 必须递归实现
D) 需要额外空间存表
= A
+ DP 保留多种可能到后面再比较，贪心只留一条路；所以贪心快，但适用面窄。

? 迁移: 最小生成树的 Kruskal 属于贪心，它成立的根源是？
A) 图一定是连通的
B) 边权是整数
C) 拟阵结构保证了「跨切割的最轻边」一定能接进某棵最小生成树
D) 并查集很快
= C
+ 切割性质给出交换论证：跨某个切割的最轻边必然属于某棵 MST，于是按权升序挑边不会走错。

## 字符串匹配

### KMP 算法在失配时不回退主串指针，靠的是什么？
A) 预处理出的 next 数组，记录模式串中最长的「相等真前后缀」长度
B) 把主串反过来
C) 哈希表存所有子串
D) 增大模式串长度
= A
+ 已匹配的那段里，最长相等前后缀告诉我们「模式串可以直接滑到哪个位置继续比」，主串只往前走。

? 理解: KMP 预处理 O(m)、匹配 O(n)，总复杂度是？
A) O(n + m)
B) O(nm)
C) O(n log m)
D) O(m²)
= A
+ 主串指针单调右移、模式串指针也只整体前进，摊还下来是线性的；与朴素 O(nm) 的差别就在这里。

? 迁移: 模式串 "abab" 的最长相等真前后缀长度是？
A) 2（"ab"）
B) 1
C) 3
D) 0
= A
+ 真前后缀不含整串本身；"ab" 既是前缀也是后缀，"aba" 不是后缀，所以是 2。

### Rabin-Karp 用滚动哈希做字符串匹配，为什么命中后仍需逐字符比对？
A) 哈希相等只是可能匹配，冲突会产生假阳性
B) 哈希计算太慢
C) 模式串长度会变
D) 主串必须有序
= A
+ 哈希把字符串压成一个数，不同串可能撞到同一个值；命中之后再验一次才能确认，最坏情况仍会退化。

? 理解: 「滚动」指的是什么？
A) 把字符串循环移位
B) 窗口右移一格时，用去掉首字符、加上新字符的 O(1) 更新替代重新计算
C) 多次随机取模
D) 按块旋转数组
= B
+ 把哈希看成多项式求值，窗口右移就是减掉最高次项、乘底数、加新项，常数时间完成。

? 迁移: 多模式匹配（同时找几千个模式串）更适合哪种结构？
A) Aho-Corasick 自动机，一次扫描主串
B) 每个模式串各跑一次 KMP
C) 二分查找
D) 并查集
= A
+ AC 自动机给 Trie 加上失配指针，把所有模式合并成一台状态机，代价与模式总长加主串长成正比。

### 取模哈希里把模数取得更大（或用双哈希），主要降低的是什么？
A) 不同字符串被判成同一个哈希值的概率
B) 单次计算的时间
C) 主串的长度
D) 字符集的大小
= A
+ 值域越大、两个独立模数同时撞上的机会越小；它降低的是概率，不是把冲突彻底消掉。

? 理解: 用无符号 64 位整数「自然溢出」当哈希，本质上是？
A) 模 2^64 的多项式哈希
B) 加密哈希
C) 无冲突哈希
D) 前缀和
= A
+ 溢出就是自动取模 2^64，写起来省事，但模数固定，构造性冲突比随机大素数模更容易被针对。

? 迁移: 判定两个长字符串的任意子串是否相等，哈希相比逐字符比较的价值是？
A) 结果绝对准确
B) 把 O(L) 的比较变成 O(1) 的期望判定，适合大量区间询问
C) 不需要预处理
D) 空间一定更省
= B
+ 预处理前缀哈希后任意子串哈希 O(1)；代价是要接受一个可控的误判概率，或在命中后确认一次。

### Manacher 求最长回文子串能做到 O(n)，关键技巧是？
A) 枚举每个中心后二分长度
B) 利用回文的对称性复用已算出的半径，并维护当前最右回文区间
C) 把字符串排序
D) 复用 KMP 的 next 数组
= B
+ 若当前中心落在已知回文区间内，它的半径至少等于镜像中心的半径，于是每个位置只被真正扩展常数次。

? 理解: 处理偶数长度回文时，常见的预处理是？
A) 在字符间插入统一分隔符，把奇偶统一成奇数长度
B) 只检查奇数中心
C) 把字符串反转拼接
D) 删除重复字符
= A
+ 插入 # 之类的分隔符后，所有回文都有唯一中心，代码里只需要一套奇数扩展逻辑。

? 迁移: 朴素中心扩展法的最坏复杂度是？
A) O(n²)，例如全同字符的串
B) O(n)
C) O(n log n)
D) O(1)
= A
+ 每个中心都可能扩展到整串长度，2n-1 个中心乘起来是平方级；Manacher 省掉的正是这些重复扩展。

### 编辑距离（插入/删除/替换各代价 1）的标准 DP，状态转移不包含哪一项？
A) dp[i][j] = dp[i-1][j] + dp[i][j-1]
B) 相等时 dp[i-1][j-1]
C) 不等时 dp[i-1][j-1] + 1（替换）
D) dp[i-1][j] + 1 与 dp[i][j-1] + 1（删 / 插）
= A
+ 正确转移是取「删、插、替换或直接匹配」三者最小值，绝不会把两个状态的代价相加 —— 那是在算路径数。

? 理解: 编辑距离 DP 的第一行第一列为什么初始化成 0..n？
A) 把空串变成长度 k 的串，必然要做 k 次插入
B) 为了让数组下标从 1 开始
C) 因为字符相等
D) 因为单次代价是 1
= A
+ 边界不是随便填的，它本身就是「与空串对齐」这个子问题的解。

? 迁移: 若只允许插入和删除，一次「替换」等价于几次操作？
A) 2 次（删 + 插）
B) 1 次
C) 0 次
D) 3 次
= A
+ 这也是编辑距离与 LCS 的关系：只允许增删时，最少操作数 = 两串长度之和 − 2×LCS。

## 回溯与搜索

### 回溯法与单纯 DFS 的主要区别是？
A) 每做一步选择都带着「撤销」动作，把状态恢复到分叉前
B) 回溯不用递归
C) 回溯只用于图
D) DFS 不能遍历树
= A
+ 回溯是在解空间树上做 DFS，但它要求状态可回滚，否则一条分支的修改会污染另一条分支。

? 理解: 全排列的回溯里，used 数组的作用是？
A) 防止同一个元素在一条路径里被重复选取
B) 记录答案数量
C) 加快排序
D) 压缩空间
= A
+ 它是「当前路径上已经用过什么」的标记；进入下一层置位、返回时清掉，正是撤销动作。

? 迁移: 剪枝通常分哪两类？
A) 可行性剪枝（再走下去必然无解）与最优性剪枝（不可能超过当前最好解）
B) 前向剪枝与后向剪枝
C) 时间剪枝与空间剪枝
D) 奇剪枝与偶剪枝
= A
+ 前者砍掉不可行分支，后者用已找到的上界砍掉没有希望的分支，两者都在缩小解空间树。

### N 皇后问题里，用位掩码记录列与对角线占用，主要收益是？
A) 把复杂度从指数降到多项式
B) 把「当前位置能不能放」的判断压成一次位运算，常数极小
C) 不需要回溯
D) 保证一次找到全部解
= B
+ 状态仍是枚举所有摆法（指数级），但每一步的冲突检测和状态更新都变成几条位指令，实际快很多。

? 理解: 主对角线（左上到右下）上的格子满足什么关系？
A) 行号减列号为定值
B) 行号加列号为定值
C) 行号等于列号
D) 行号乘列号为定值
= A
+ 同一条 ↘ 对角线上 r − c 不变，另一方向则是 r + c 不变；偏移后用位标记即可。

? 迁移: 位运算优化改变了解空间规模吗？
A) 没有，仍是指数级，只是每个节点的常数变小
B) 变成了 O(n²)
C) 变成了 O(n log n)
D) 变成多项式
= A
+ 优化的是「判断一次冲突」的成本，不是「要判断多少次」；N 皇后本身的解空间没有变小。

### 在状态数随深度按 b^d 增长的图上，双向 BFS 的收益来自？
A) 它不需要队列
B) 两边各搜 d/2 层，总量约 2·b^(d/2) 而不是 b^d
C) 它把边权变成 1
D) 它额外保证最短路
= B
+ 指数函数拆成两半再做加法，量级大幅下降；前提是能生成反向边，从终点往回搜。

? 理解: 双向 BFS 每一轮扩展哪一侧更合适？
A) 通常扩展当前队列节点更少的一侧，让两边规模保持均衡
B) 永远先扩展起点侧
C) 永远先扩展终点侧
D) 随机挑一侧
= A
+ 总代价由较大的那棵搜索树主导，压住大的一侧才能真的拿到开方级收益。

? 迁移: 下面哪类问题不适合双向 BFS？
A) 状态转移不可逆、无法从目标反推前驱的问题
B) 字谜变换（每次改一个字母）
C) 无权图两点间最短路
D) 八数码
= A
+ 反向搜索要求有明确的逆操作；单向的状态转移（比如某些哈希过程）没法从终点倒着走。

### A* 能保证找到最优解，对启发函数 h 的关键要求是？
A) h 恒为 0
B) h 越大越好
C) h 不高估到目标的实际代价（可采纳性），并满足一致性
D) h 必须是整数
= C
+ 不高估才不会把真正的最优路径提前排除；一致性（三角形不等式）保证节点首次出队时代价已经最优。

? 理解: h 恒等于 0 时，A* 退化成什么？
A) Dijkstra（等价的均匀代价搜索）
B) 贪心最佳优先搜索
C) 深度优先搜索
D) BFS 加剪枝
= A
+ 只剩 g(n) 排序就是 Dijkstra；反过来只看 h 不看 g，是贪心最佳优先，不再保证最优。

? 迁移: 网格上只能上下左右走、每步代价 1，常用且可采纳的 h 是？
A) 曼哈顿距离
B) 欧氏距离的平方
C) 直线距离乘 2
D) 当前已走步数
= A
+ 无障碍时曼哈顿距离就是真实最少步数；有障碍时它是下界，不会高估，因此可采纳。

### 迭代加深搜索（IDDFS）主要解决 DFS 的什么问题？
A) 深度优先可能一头扎进无限深的分支，IDDFS 逐层加深度上限保证先找到最浅解
B) DFS 内存太大
C) DFS 不能回溯
D) DFS 不能用于树
= A
+ 它把「BFS 的最浅优先」和「DFS 的 O(d) 空间」拼在一起；重复搜索的开销被指数增长的分支数摊薄了。

? 理解: IDDFS 反复搜索浅层，时间复杂度会不会变得不可接受？
A) 不会，在分支因子大于 1 的树上，最后一层的节点数主导总量，仍是同阶
B) 会，变成 O(n²)
C) 会，变成指数平方
D) 无法分析
= A
+ 各层节点数是 1, b, b², …，几何级数由最大的一项主导，重复前面几层只多一个常数倍。

? 迁移: 空间受限但要求「找到最少步数的解」，首选是？
A) IDDFS 或 IDA*
B) 普通 BFS
C) 普通 DFS
D) 双向 DFS
= A
+ BFS 要存整层节点，DFS 不保证步数最少；IDDFS 两头都照顾到，IDA* 再加上启发式剪枝。

## 随机化与概率

### 从长度未知的数据流里等概率抽 1 个元素，蓄水池抽样的做法是？
A) 先把全部数据存下来再随机
B) 第 i 个元素以 1/i 的概率替换当前保留的那个
C) 永远保留第一个
D) 每隔固定间隔取一个
= B
+ 归纳可证：处理到第 i 个时，前面任一个被保留的概率都是 1/i；不需要预先知道 n，空间 O(1)。

? 理解: 为什么替换概率必须是 1/i 而不是一个固定值？
A) 要让每个已见过的元素在任意时刻被保留的概率都相等
B) 固定值会溢出
C) 1/i 计算更快
D) 数据流长度就是 i
= A
+ 固定概率会让早来的元素被反复替换、概率不断衰减；1/i 恰好抵消了后续所有替换的影响。

? 迁移: 要抽 k 个元素，第 i 个元素（i > k）被选中并替换蓄水池中某一位置的概率是？
A) k/i
B) 1/i
C) 1/k
D) i/k
= A
+ 以 k/i 的概率入选，再从 k 个槽里均匀挑一个替换；最终每个元素入池概率都是 k/n。

### Fisher-Yates 洗牌为什么是均匀随机的？
A) 它交换了足够多次
B) 第 i 步从 [0, i] 里均匀选一个与 i 交换，每个排列恰好对应一组等概率的选择
C) 它用了加密级随机数
D) 它先排序再打乱
= B
+ n! 个排列与 n × (n-1) × … × 1 组选择一一对应，每组概率都是 1/n!，所以没有偏斜。

? 理解: 常见错误写法「对每个 i，随机 j 属于 [0, n) 后交换 i 和 j」有什么问题？
A) 会死循环
B) 产生 n^n 条等概率路径，而 n! 不能整除 n^n，各排列概率不均等
C) 数组会越界
D) 结果一定有序
= B
+ 当 n=3 时 27 条路径要塞进 6 个排列里，必然有的排列分到 4 条、有的分到 5 条。

? 迁移: 从 n 个数里随机取 m 个不重复的样本，最省事的正确做法是？
A) 洗牌后取前 m 个，或做 m 轮 Fisher-Yates 的部分交换
B) 循环 random() 直到凑够不重复的 m 个
C) 取 random() 生成的连续 m 个数
D) 排序后取前 m 个
= A
+ 「抽到重复就重抽」在 m 接近 n 时会急剧变慢，而部分洗牌固定 O(m) 且保证均匀。

### 随机化枢轴让快速排序的期望复杂度变成 O(n log n)，它消除的是？
A) 比较操作本身
B) 特定输入与固定枢轴规则「合谋」构造出的最坏划分
C) 递归调用
D) 额外的空间开销
= B
+ 最坏输入还在，但它不再由输入顺序决定，而是由随机结果决定；对任意固定输入，期望都是 O(n log n)。

? 理解: 「期望 O(n log n)」和「最坏 O(n log n)」的区别是？
A) 前者是对枢轴随机性取平均，仍存在极低概率的 O(n²) 运行
B) 两者相同
C) 前者更弱且不可能达到
D) 前者只对有序数组成立
= A
+ 随机化不改写最坏情况，只把最坏情况从「可预测的规律」变成「小概率事件」。

? 迁移: 想拿到确定性的最坏线性时间选择，应该用什么？
A) median-of-medians（BFPRT）
B) 三数取中
C) 随机化枢轴
D) 堆排序
= A
+ 它用分组取中位数的中位数做枢轴，保证划分比例有常数下界；代价是常数很大，工程上少用。

### 「蒙特卡洛算法」和「拉斯维加斯算法」的区别是？
A) 前者只用于数值积分
B) 前者时间确定但结果可能错，后者结果一定对但运行时间是随机的
C) 后者一定更快
D) 两者完全一样
= B
+ 米勒-拉宾素性测试属于前者（可控的单边错误概率），随机化快排属于后者（永远排对，只是耗时随机）。

? 理解: 想降低蒙特卡洛算法的错误率，常用手段是？
A) 用独立随机数重复运行多次，让错误概率相乘
B) 增加数组长度
C) 改用递归
D) 提高数值精度
= A
+ 单次错误率 p、独立重复 k 次后降到 p^k；前提是每次的随机性真的独立。

? 迁移: 随机化快排属于哪一类，为什么？
A) 拉斯维加斯：排序结果始终正确，只有耗时随枢轴变化
B) 蒙特卡洛：可能排错
C) 两者都不是
D) 取决于输入
= A
+ 它不牺牲正确性，随机性只用来避开坏输入；这是区分两类算法最快的检验方式。

### 计算随机变量的期望时，「期望的线性性」最有用的地方是？
A) 能把乘积的期望拆成期望的乘积
B) 不需要变量相互独立，也能把和的期望拆成期望的和
C) 只适用于均匀分布
D) 能消除方差
= B
+ 指示变量法正靠这一点：把复杂计数拆成一堆 0/1 变量，各自求期望再相加，完全绕开相关性。

? 理解: 抛 n 次公平硬币，正面朝上次数的期望是？
A) n/2
B) n
C) 1/2
D) √n
= A
+ 令 X_i 为第 i 次是否正面的指示变量，E[X_i]=1/2，加起来 n/2；不必去算二项分布的完整公式。

? 迁移: 赠券收集问题（每种等概率，要集齐 n 种）的期望抽取次数约为？
A) n ln n
B) n
C) n²
D) log n
= A
+ 已有 k 种时，抽到新种类的概率是 (n-k)/n，等待期望是 n/(n-k)，求和得 n·H_n ≈ n ln n。
