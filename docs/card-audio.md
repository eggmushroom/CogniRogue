# CogniRogue 卡牌音效设计

让玩家不用盯着牌堆也能区分「拿起一张」「从牌堆抽出」「放回弃牌堆」。听清楚操作比给每个动作都配音更重要；音效不代替动画、数字或反馈面板。

## 参考与取舍

- [《炉石传说》音效团队访谈](https://news.blizzard.com/en-us/article/23964694/inside-battle-net-meet-the-sound-team-behind-hearthstones-harmonic-design)：用拖牌、落牌、施法和命中等节拍来组织声音，也要判断什么时候不响。这里把手上纸牌的声音和战斗结算声分开，不复制其素材。
- [Game Accessibility Guidelines：为不同对象和事件设计可区分的声音](https://gameaccessibilityguidelines.com/use-distinct-sound-music-design-for-all-objects-and-events/)：三个卡牌动作使用同一种纸卡质感，但起音、长度和重量不同，而不只是把同一素材换成不同音量。
- [Kenney Casino Audio](https://kenney.nl/assets/casino-audio)：卡纸拟音素材（CC0），本项目裁剪和混合后的来源见 [SOURCES.md](../assets/sfx/SOURCES.md)。

## 听觉规则

| 玩家动作 | 何时发声 | 听感 |
| --- | --- | --- |
| 选牌 | 知识牌成功打开题面，或选中奖励、精炼预览、遗忘目标 | 最轻、最短的一下纸边拨动；扫过牌面、无效点击、取消都不响 |
| 抽牌 | 等弃牌落堆与敌方动作后，第一张离开牌堆；抽牌若是一手牌的主效果，在该手结算时响 | 先松动再滑出的纸摩擦，一批一声 |
| 弃牌 | 回合末第一张未打出的牌落入弃牌堆 | 先闷落，随后是很轻的纸边贴合；不逐张叠响 |
| 直接打牌、答题结算 | 主效果发生时 | 只播主效果；攻击优先且保留多段穿刺。有攻击和格挡的牌不叠出牌、抽牌或护盾声，也不把正常出牌当成弃牌 |

攻击、挨打和碰盾仍比高频纸牌操作更突出。选牌和弃牌不新增提示音轨，保留同一个战斗音效开关，并继续适配离线 HTML。

## 实战验收

- 闭眼听一轮能否区分选牌、回合末落堆和下一轮抽牌？如果只能靠音量区分，先修素材的起音和纸感。
- 连续几轮里，鼠标扫牌是否安静、纸声是否抢过穿刺、同一张复合牌是否多响？先查触发时机和重复播放，而不是先加音乐。
- 浏览器冒烟覆盖上述触发、顺序、优先级和静音偏好；真实听感仍需通过完整牌局试听。
